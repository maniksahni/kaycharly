IMPRESSION AUTOMATIQUE DES COMMANDES

Imprimante

Quand cette page est ouverte, chaque nouvelle commande s’imprime toute seule (ticket coupé automatiquement) et un son retentit. Le site vérifie chaque étape en direct et coche ✓ quand elle est faite.

Si ça ne marche pas, pas de souci : le bouton passe tout seul à la méthode suivante. Cliquez-le à nouveau jusqu’à ce qu’un ticket sorte.
Un ticket « IMPRIMANTE CONNECTÉE » est-il sorti de l’imprimante ?

    Connexion utilisée : Aucune

    Choisir une méthode précise
    MISE EN PLACE · À FAIRE UNE SEULE FOIS

    Les étapes

    1. Mettre le papier. Ouvrez le capot de l’imprimante. Posez le rouleau de 80 mm pour que le papier sorte par-dessus, vers vous (côté brillant vers l’extérieur). Laissez dépasser un peu de papier et refermez le capot en appuyant fort jusqu’au « clic ».
    2. Brancher et allumer. Câble d’alimentation dans la prise, câble USB dans l’ordinateur. Appuyez sur l’interrupteur : le voyant s’allume et l’imprimante fait un bip.
    3. Ouvrir ce site avec Google Chrome, se connecter, puis ouvrir l’onglet « 🖨️ Imprimante ».
    4. Cliquer sur le gros bouton. Une liste s’ouvre en haut : cliquez sur le nom de l’imprimante, puis sur « Connexion » (ou « Associer »). Un ticket sort tout seul : répondez « Oui, il est sorti ». C’est fini ! Si l’imprimante n’est pas dans la liste ou si un message rouge apparaît, recliquez sur le gros bouton : il essaie automatiquement la méthode suivante (câble USB → sans fil → Bluetooth appairé → pilote).
    5. Pour la méthode « Bluetooth appairé » : il faut d’abord appairer l’imprimante. Démarrer → Paramètres → Bluetooth et appareils → Ajouter un appareil → Bluetooth → cliquez sur l’imprimante (si un code est demandé : 0000 ou 1234). Revenez ici, cliquez sur « Connecter en Bluetooth », choisissez la ligne de l’imprimante (avec « COM »), puis « Connexion ».
    6. Dernier recours : le pilote de l’ordinateur. Le plus simple : dans l’assistant, téléchargez le lanceur « Kay Charly Caisse » et ouvrez-le (il règle tout et démarre avec l’ordinateur). À la main : Installez le pilote fourni avec l’imprimante, puis Paramètres → Bluetooth et appareils → Imprimantes et scanners → l’imprimante → « Définir par défaut ». Créez le raccourci « Kay Charly Caisse » (clic droit sur le bureau → Nouveau → Raccourci) avec :"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing https://maniksahni.github.io/kaycharly/admin.html Fermez Chrome complètement, ouvrez l’admin avec ce raccourci, puis cliquez sur « Utiliser le pilote de l’ordinateur ». Si Windows dit que le fichier est introuvable, remplacez Program Files par Program Files (x86).
    7. Laisser tourner. Gardez cette page ouverte devant les autres fenêtres, l’ordinateur branché, et réglez Paramètres → Système → Alimentation → Écran et veille sur « Jamais ». Gardez un rouleau de 80 mm de rechange.
    1. Mettre le papier (rouleau 80 mm, papier qui sort par-dessus vers vous), refermer le capot jusqu’au « clic ».
    2. Brancher et allumer : alimentation + câble USB dans le Mac.
    3. Ouvrir ce site avec Google Chrome, se connecter, onglet « 🖨️ Imprimante ».
    4. Cliquer sur le gros bouton, choisir l’imprimante dans la liste, « Connexion » (ou « Associer »). Un ticket sort : répondez « Oui ». Si ça ne marche pas, recliquez : le bouton essaie tout seul la méthode suivante (USB → sans fil → Bluetooth appairé → pilote).
    5. Pour « Bluetooth appairé » : Réglages Système → Bluetooth → se connecter à l’imprimante d’abord.
    6. Laisser tourner : page ouverte au premier plan, Mac branché, veille désactivée.
    Un problème ? Les solutions
    • Rien ne sort mais le site dit « imprimé » : le rouleau est à l’envers. Retournez-le (côté brillant vers l’extérieur), refermez le capot.
    • « Capot ouvert » : appuyez fort sur le capot jusqu’au clic.
    • « Plus de papier » : mettez un nouveau rouleau de 80 mm.
    • « Connexion perdue » : vérifiez les câbles, éteignez et rallumez l’imprimante, puis « Revérifier ».
    • Une fenêtre d’impression s’ouvre à chaque commande : vous utilisez le pilote sans le raccourci « Kay Charly Caisse » (étape 6).
