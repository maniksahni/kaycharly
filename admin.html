    MISE EN PLACE · À FAIRE UNE SEULE FOIS

    Les étapes

    1. Brancher l’imprimante. Câble USB branché sur l’ordinateur, imprimante allumée, papier en place, capot fermé. Le voyant vert « Editor Lite » doit être éteint (appuyez sur son bouton s’il est allumé).
    2. La mettre par défaut dans Windows. Démarrer → Paramètres → Bluetooth et appareils → Imprimantes et scanners → Brother QL-700 → « Définir par défaut ». Désactivez « Laisser Windows gérer mon imprimante par défaut ».
    3. Créer le raccourci « Kay Charly Caisse » (pour imprimer sans fenêtre). Clic droit sur le bureau → Nouveau → Raccourci, collez :"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing https://maniksahni.github.io/kaycharly/admin.html puis nommez-le « Kay Charly Caisse ». Si Windows dit que le fichier est introuvable, remplacez Program Files par Program Files (x86). Fermez complètement Chrome (toutes les fenêtres), puis ouvrez l’admin uniquement avec ce raccourci. Astuce : copiez aussi ce raccourci dans le dossier shell:startup (Windows + R) pour qu’il s’ouvre au démarrage.
    4. Choisir l’imprimante ici : cliquez sur « Imprimante de l’ordinateur » ci-dessus. Un ticket test sort, répondez à la question.
    5. Laisser tourner. Gardez cette page ouverte et devant les autres fenêtres, l’ordinateur branché sur le secteur, et réglez Paramètres → Système → Alimentation → Écran et veille sur « Jamais ».
    1. Brancher l’imprimante en USB, allumée, papier en place, voyant « Editor Lite » éteint.
    2. Choisir l’imprimante ici : « Imprimante USB directe (Brother) » si elle apparaît dans la liste ; sinon installez le pilote Brother, mettez la QL-700 par défaut (Réglages → Imprimantes) et choisissez « Imprimante de l’ordinateur ».
    3. Pour imprimer sans fenêtre avec l’imprimante de l’ordinateur : quittez Chrome, puis dans Terminal : open -a "Google Chrome" --args --kiosk-printing https://maniksahni.github.io/kaycharly/admin.html
    4. Laisser tourner : page ouverte au premier plan, Mac branché, veille désactivée.
